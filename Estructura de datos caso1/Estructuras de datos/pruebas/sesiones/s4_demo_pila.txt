OPERACIONES DE LA PILA (todas O(1))
  push(t)  : inserta el token t en la cima
  pop()    : retira y devuelve el token de la cima
  peek()   : devuelve la cima sin retirarla
  isEmpty(): indica si la pila está vacía

Demostración con una pila nueva:
  isEmpty() -> true

  push(()  -> [ ( ]
   +-----+
   |  (  |  <-- CIMA
   +-----+

  push(+)  -> [ ( , + ]
   +-----+
   |  +  |  <-- CIMA
   +-----+
   |  (  |
   +-----+

  push(*)  -> [ ( , + , * ]
   +-----+
   |  *  |  <-- CIMA
   +-----+
   |  +  |
   +-----+
   |  (  |
   +-----+

  peek() -> *   (la pila no cambia: [ ( , + , * ])
  pop()  -> *   pila: [ ( , + ]
  pop()  -> +   pila: [ ( ]
  pop()  -> (   pila: [ ]
  isEmpty() -> true
  pop() con la pila vacía -> Subdesbordamiento: no se puede hacer pop en una pila vacía.
